# AI DRS — Single-Camera LBW System

A research-oriented, AI-assisted cricket LBW review system using **one fixed smartphone camera positioned behind the bowler**.

## Documents

- `PRD.md` — product requirements
- `TRD.md` — technical requirements
- `EXECUTION_PLAN.md` — implementation roadmap and LOOP execution control

## Core Principle

Build from:

**mobile video → calibration → ball tracking → event detection → trajectory → LBW evidence → decision**

The system supports:

**OUT / NOT OUT / INCONCLUSIVE**

The project does not claim official or professional DRS accuracy.

## Development Start

Follow `EXECUTION_PLAN.md`.

The first milestone is repository/environment setup, followed by video ingestion and camera feasibility testing.
